Einstellungen

Zugangsdaten und Kanal für deinen Bot.

  1. Öffne die Twitch-Entwicklerkonsole und klicke auf Anwendung registrieren.
  2. Name: frei wählbar, z. B. bot-zentrale-deinname.
    OAuth-Redirect-URL: http://localhost:3000/auth/callback
    Kategorie: Website Integration, Client-Typ: Vertraulich.
  3. Auf Erstellen, dann Verwalten klicken. Die Client-ID kopieren und mit Neues Geheimnis das Client-Secret erzeugen.
  4. Beides unten eintragen. Das Secret wird verschlüsselt auf diesem PC gespeichert.
Wie in der Kanal-URL, nicht der Anzeigename.
Twitch-Namen, mit Komma getrennt.
Standard 3000. Bei Änderung auch die Redirect-URL bei Twitch anpassen.
Datenbank optional

Leer lassen: Alles wird lokal auf diesem PC gespeichert. Mit einer Postgres-Adresse (z. B. Supabase oder dein eigener Server) liegen die Daten online. Beim ersten Start werden deine lokalen Daten automatisch übernommen.

Supabase: Projekt → Connect → Session pooler → Adresse kopieren und dein Datenbank-Passwort einsetzen.
Damit prüft der Bot, dass er wirklich mit deiner Datenbank spricht. Supabase: Database → Settings → SSL Configuration → Zertifikat herunterladen.
